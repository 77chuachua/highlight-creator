前往时间（标题是跳转到指定时间）—— go_to_dialog.dart → GoToDialog， AlertDialog，key goto_dialog。 两组三格时间输入：目标时间 + 可选的基准时间，每组三个 64px 宽、居中、只能输数字的小框 （hh / mm / ss；issues.md 要求拆成三格，不是一个文本框）。 实际跳转 = 目标 − 基准（基准为空时就是目标），负数按 0 算； 空格子按 0，分、秒必须在 0–59，任何一格非数字或越界都只在内容底部显示 「时间格式无效，请使用 时:分:秒」，对话框不关。 基准时间会记住（存 hh:mm:ss，清空则存空串），所以下次打开中间一栏是回填好的； 目标那栏的 hh 一打开就带焦点。
这个对话框不选源、不选片段：跳转发生在「所有源按顺序拼接」的总时间轴上—— 总时长已知时先算出落在第几个源、在该源的本地偏移处加载并播放；只有一个源又没有时长元数据时直接在该源内跳； 超过总时长就截断到结尾。入口：我要 → 跳转到指定时间，或 Ctrl + G （光标在输入框里打字时热键不触发）。

片段拆分（标题是时间片段分类明细）—— clip_breakdown_dialog.dart → ClipBreakdownDialog，从 我要 → 时间片段分类明细 打开（项目里一条片段都没有时，这个菜单项是灰的）。 820×700 的固定窗口，正文自己滚。 眉标一行 项目名 · 共 N 条 · 进攻 X · 防守 Y，只有存在未分类时才多出一段 · 未分类 Z。 正文按类分段：标题 进攻 N 条 + 右侧「复制」，段内一行一条 序号 描述； 序号是这条片段在整个项目里的 1-based 位置——和 Make 时转场卡上印的编号是同一个数。 分类不是人工分的：classifyClip() 按关键词判定（没收 / 扑出 / 扑救 / 门将 / 出击…是防守， 进球 / 破门 / 得分 / 助攻 / 门梁 / 门柱…是进攻，两边都不中才是未分类）， 未分类照样显示、不会被藏起来；空描述写成「（无描述）」。 底栏左边那句是给评审看的规则说明：「序号与 Make 时转场卡上的编号一致」。 「复制全部」只拼进攻 + 防守两段（空段写「（无）」，两段之间空一行），未分类不进剪贴板； 每段和全部各弹一句「已复制…」，2 秒后自己消失。

放大定位点（标题是设置放大的画面中心）—— zoom_in_point_dialog.dart → ZoomInPointDialog，Make 流程的第一步 （control_panel.dart → openMakeFlow()）：只有勾了「远端」的片段会进这个对话框， 设完放大中心才轮到「预览与确认」。 画面是每个远端片段入点那一帧（extractFrame(timestampSecs: inPointMs / 1000)， 抽到结果目录的 zoom_point_frame_<i>.png，关窗时删掉）。 鼠标移进来是十字准星（白 50%、1px）；左键记一个红点（实心圆 r=8 + 上下左右各 12px 十字）， 右键清掉当前点；坐标按画面比例归一化成 0–1，最后写回片段的 centerX / centerY。 「应用到所有」默认勾着：这时「下一步」是灰的（一步设完就够），完成会把第一个点盖到所有远端片段上； 取消勾选后才能一片一片点「下一步」，最后一页的「下一步」同样不可用。 帧没抽出来时画面区只显示「无法加载画面」，照样能完成（没标记 = 这些片段不改动）。 点 ✕ 等于取消，返回空，一个片段都不动。
