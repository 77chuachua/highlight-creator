Highlight Creator · 界面原型

这套页面是静态原型，逐屏对照当前实现绘制（尺寸、文案、配色都取自代码）， 用浏览器直接打开即可，不需要构建。改动界面后请同步这里，保持一致。
原型覆盖范围：主窗口全部区域（工具栏 / 播放器 / 源文件 / 模板面板 / 控制条 / 时间轴 / 时间片段表 / 状态栏）、 模板编辑器与预览、标注与引导对话框、手机打点、设置，五佳球两步流程（成片缓存回填、试听版本复用、seed 输入）、 语音包相关对话框、缓存对话框、语音工作室、AI 打点。
