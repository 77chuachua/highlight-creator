五佳球 · 界面原型

这套页面是静态原型，逐屏对照当前实现绘制（尺寸、文案、配色都取自代码）， 用浏览器直接打开即可，不需要构建。改动界面后请同步这里，保持一致。
原型覆盖范围：五佳球两步流程、语音包相关对话框、缓存对话框、语音工作室。

打开方式

直接双击 docs/ux/index.html，或用任何静态服务器托管 docs/ux/。 页面不依赖网络与脚本（除 assets/proto.css），离线可看。
