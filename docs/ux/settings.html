设置 —— settings_screen.dart → SettingsScreen， 由控制栏的齿轮按钮打开（main_window.dart → _showSettings()）， 外层是 Dialog(child: SizedBox(width: 500, child: SettingsScreen()))， 宽 500、高度随内容，对话框本身没有底部按钮：点外面或 Esc 关闭。 内容是「标题 + 可滚动列表」，列表按代码顺序分成五段： 主题 / 语言 / 快捷键 / 帮助 / 关于，每段之间一条分隔线。
控件都是 ListTile + 右侧箭头（点开一个单选对话框），没有开关、也没有下拉框； 「关于」是唯一没有箭头、点了也没反应的一行，只显示应用名与版本。 主题默认 dark（副标题显示「深色」），语言默认 English； 本页是中文界面，所以语言行副标题是「中文」。 文案逐字取自 app/lib/data/l10n.dart 的 _zh （settingsTitle / languageSection / languageLabel / hotkeySection / hotkeyTitle / helpSection / guideTitle / aboutSection / appName / appVersionInfo）， 「主题」「选择主题」「深色」「浅色」是 _s(zh, en) 里的中文字面量。
