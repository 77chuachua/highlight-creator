试听即抽卡：克隆质量每次都有波动。语音行下面多了一行 seed 输入框 （默认 50，范围 0 – 4294967295）：填什么种子就用什么种子抽， 同一 seed + 同一句台词 + 同一语音包会得到同一版；超出范围时输入框描边变红， 右侧提示变成 ⚠ seed 必须是 0 – 4294967295 之间的整数，此时「试听」和「生成」都会拒绝执行。 听到满意的那一版会被保存为这份解说的 take，状态行变成 解说:我的声音(本地克隆 · 用已试听版本)；点「生成」时台词和语音包没变就直接用这份 take， 不再克隆。改了台词或换了语音包，take 失效，生成时才重新克隆。
试听右边的 ▶（「播放上次试听」）直接播放保存下来的那一版，不重新克隆； 还没有 take（或台词改过）时它是灰的，点不动。▶ 右边的 seed 1734567890 是这一版的种子，填到语音工作室的 seed 输入框就能复现同一版。
黑屏排查：预览两次都拿不到画面时，视频区会显示「画面没有出来(已记录日志),再点一次 ▶ 重新加载播放器」， 日志里对应 [top5] preview=no_picture … / preview=black …， 带 w/h/duration/mpv 原始报错；换新播放器后成功的记为 preview=recovered retry=1。
